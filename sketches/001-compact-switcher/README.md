## Variant: Compact workspace switcher

### Design stance
A utilitarian split-pane treats login as a fast workspace switcher for a multi-role university operation.

### Key choices
- Layout: Persistent dark rail paired with a compact access panel.
- Typography: Dense labels and measurable campus stats.
- Color: Navy utility rail, pale mint context panel, teal action.
- Interaction: Role tabs swap demo identities; continue shows the selected workspace.

### Trade-offs
- Strong at: Role switching, repeat visits, information density, operational clarity.
- Weak at: Emotional warmth and large-screen visual drama.

### Best for
- Mixed audiences where faculty, staff, and administrators need equal prominence.
