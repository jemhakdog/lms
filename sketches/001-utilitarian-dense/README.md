## Variant: Utilitarian Dense

### Design stance
A power-user tool — pack every operationally important signal into the first scroll, treat whitespace as wasted real estate, and let the keyboard do the work.

### Key choices
- **Layout:** Persistent dark left sidebar (220px) + 6-up metric row + 3-column dense grid; everything fits above the fold
- **Typography:** 13px body, system stack, tabular numerals for metrics — built for scanning, not reading
- **Color:** High-contrast neutral (zinc grays) with one accent (blue 600). Status pills are the only color: green/amber/red for fill rates, blue/gray for request state
- **Interaction:** Hover rows, tab filters, dense pills, search bar with `⌘K` affordance implicit. Everything is a click target.

### Trade-offs
- **Strong at:** Seeing the operational state of the department at a glance, scanning many courses/sections simultaneously, finding bottlenecks fast
- **Weak at:** Comfortable for casual check-ins, mobile use, anyone not already fluent in academic ops

### Best for
- Department chairs, schedulers, ops staff who log in daily and want to triage quickly
- A "control room" feeling rather than a "front door"
