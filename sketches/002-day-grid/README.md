## Variant: Day grid

### Design stance
The dashboard mirrors how faculty actually think: today is a sequence of time blocks, and other things hang off that timeline. Schedule first; everything else is a sidebar.

### Key choices
- Layout: Persistent dark left rail, day timeline as the hero, right column for grading queue and inbox.
- Typography: Inter throughout, tabular numerals for stats and time, tight line-height for density.
- Color: Navy utility rail, mint context, teal accent, terracotta for overdue grading.
- Interaction: Day-pill navigation (Wed/Thu/Fri); now-indicator on the current class slot; per-class location chips.

### Trade-offs
- Strong at: Operational clarity, fast scanning, repeat visits, fitting many things on one screen.
- Weak at: Warmth, first-day-of-term orientation, the "what's the most important thing to do" question isn't called out.

### Best for
- Mid-semester faculty who already know the system and want a fast, all-info-at-a-glance operating surface.
